# Как включить настоящие аккаунты (≈10 минут)

Сейчас «Личный кабинет» работает в демо-режиме: аккаунты и заявки хранятся только в браузере посетителя.
Чтобы аккаунты стали настоящими и заявки приходили вам, нужна бесплатная база данных Supabase.

## 1. Создайте проект Supabase
1. Откройте https://supabase.com → **Start your project** → войдите через GitHub.
2. **New project**: имя `t-hydra`, придумайте пароль базы (сохраните его), регион — **Central EU (Frankfurt)**.
3. Подождите 1–2 минуты, пока проект создаётся.

## 2. Создайте таблицы
1. Слева **SQL Editor** → **New query**.
2. Откройте файл `supabase/schema.sql` из репозитория, скопируйте всё содержимое, вставьте и нажмите **Run**.
   Должно появиться «Success. No rows returned».

## 3. Настройте вход
1. **Authentication → URL Configuration**:
   - Site URL: `https://timur-alt2008.github.io/HYDRA-Digital-Studio/account/`
   - Redirect URLs: добавьте `https://timur-alt2008.github.io/HYDRA-Digital-Studio/**`
2. **Authentication → Providers → Email** — включено по умолчанию. «Confirm email» можно оставить:
   после регистрации человек получит письмо со ссылкой.

## 4. Передайте ключи сайту
**Project Settings → API**: скопируйте **Project URL** и ключ **anon public**.
Оба значения публичные по задумке — данные защищает база (row-level security), а не секретность ключа.
Пришлите их мне в чат — я добавлю их в настройки сайта и опубликую. (Или сами: в файл `.env`
строки `SUPABASE_URL=...` и `SUPABASE_ANON_KEY=...`, затем `npm run build`.)

⚠️ Никогда не присылайте и не вставляйте ключ **service_role** — он секретный.

## 5. Сделайте себя администратором студии
1. Зарегистрируйтесь на сайте в «Личном кабинете» своим email.
2. В Supabase: **SQL Editor** → выполните (подставьте свой email):
   ```sql
   insert into public.admins (email) values ('ваш@email.com');
   ```
3. Обновите страницу кабинета — появится вкладка **«Все заявки (студия)»**: там видны заявки всех клиентов,
   можно менять статус (Новая → На рассмотрении → В работе → Выполнена / Отклонена) и оставлять комментарий.
   Клиент увидит новый статус и комментарий у себя в кабинете.

## Как это работает
- Заявки из формы «Контакты» и из Project Builder, отправленные **после входа**, сохраняются в аккаунте и сразу видны студии.
- Каждый клиент видит только свои заявки. Это проверяет сама база, поэтому подделать запрос с сайта нельзя.
- Бесплатного тарифа Supabase хватает на тысячи пользователей; если проект неделю не используется, Supabase
  ставит его на паузу — его можно включить одной кнопкой в панели.
