HYDRA Marketplace Mini App

StatusConcept
CategoryTelegram Mini Apps
ClientConcept
Year2026
Overview

A services marketplace that runs as a full Telegram Mini App — the bot only launches it and sends notifications.

Goal

Give the marketplace a real interface inside Telegram: catalogue, orders, profiles and admin.

Approach

A monorepo with web, admin, API and shared packages; React + TypeScript + Vite on the client, Fastify and PostgreSQL with Prisma on the server. Payments stay behind a flag until later stages.

What works
  • Mini App client with Telegram auth
  • Separate order and deal statuses
  • Admin panel
  • Payment steps behind a feature flag
