Booking Mini App

StatusDemo
CategoryTelegram Mini Apps
ClientInterface demo — fictional studio
Year2026
Overview

A Telegram Mini App interface for booking a time slot, with a working bot conversation beside it. Try it on the home page.

Goal

Show how a booking flow feels when it opens inside Telegram instead of a separate website.

Approach

Mini App screens follow Telegram's interface conventions — a main button, compact lists and the user's theme — while the bot handles reminders and quick actions.

What works
  • Bot conversation with quick replies
  • Service and slot selection
  • Main-button confirmation pattern
  • Booking summary returned to the chat
