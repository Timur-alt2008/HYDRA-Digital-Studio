Fitness Club Platform

StatusDemo
CategoryWebsites
ClientExample — fictional fitness club
Year2026
timur-alt2008.github.io/Fitness-For-Example-For-my-Portfolio/
Open live demoSource on GitHub
Overview

A multi-page fitness club website with schedule, coaches, memberships, a member account and booking with live spot counts.

Goal

Show that a static site can behave like a real product: bookings, memberships and an account that respect business rules.

Approach

Hash routing and ES modules without a build step, plus a demo API layer that simulates latency, server-side validation, “fully booked” errors and double-submit protection.

What works
  • Program explorer, 7-day schedule with filters and spots left
  • Membership finder quiz, comparison table and promo codes
  • Member account: freeze, cancellations, history (demo data)
  • Demo API with idempotency keys and cancellation rules
  • BMI and calorie calculators
  • OpenStreetMap contact map
