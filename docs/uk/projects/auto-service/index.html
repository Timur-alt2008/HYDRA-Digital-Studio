Огляд

Темний преміальний сайт автосервісу, перезібраний на React + TypeScript + Vite: послуги, галерея, етапи робіт і запис.

Мета

Перенести першу статичну версію на компонентний React і підняти візуальний рівень до «преміуму».

Підхід

Компоненти на React + TypeScript, паралакс на першому екрані, каталог послуг із детальними вікнами, галерея з фільтрами й форма запису — усі демо-дані підписані.

  • Галерея з фільтрами й повноекранним переглядом
  • Шкала процесу й анімовані лічильники

  • Контакти зі схемою проїзду
