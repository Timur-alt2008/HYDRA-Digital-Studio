Booking Mini App

StatusDemo
KategorieTelegram Mini Apps
KundeInterface-Demo — fiktives Studio
Jahr2026
Überblick

Eine Telegram-Mini-App-Oberfläche zur Terminbuchung, daneben ein funktionierender Bot-Dialog. Probieren Sie es auf der Startseite aus.

Ziel

Zeigen, wie sich eine Buchung anfühlt, wenn sie direkt in Telegram statt auf einer separaten Website geöffnet wird.

Ansatz

Die Mini-App-Screens folgen den Konventionen von Telegram — Hauptbutton, kompakte Listen und das Theme des Nutzers —, während der Bot Erinnerungen und Schnellaktionen übernimmt.

Was funktioniert
  • Bot-Dialog mit Schnellantworten
  • Auswahl von Leistung und Zeitfenster
  • Bestätigung über den Hauptbutton
  • Buchungsübersicht wird in den Chat gesendet
